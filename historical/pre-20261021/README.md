# Product source variants before 21 October 2026

This directory preserves previously unuploaded EX product code versions from
before 2026-10-21 00:00 HKT (2026-10-20 16:00 UTC). Each unique content version
has its own Git-blob directory, so multiple drafts of the same module remain
separate. MANIFEST.json maps those paths to their original product module names.
Already uploaded GitHub objects were excluded after exact object lookups.

These are historical source snapshots, including incomplete or superseded drafts.
They are not imported by the active application and do not replace current
source, current PRD.md, test expectations or operation semantics. In particular,
older rollback or remint prototypes cannot reinstate retired requirements.
A snapshot's presence does not establish compilation, CI, runtime or chain
acceptance. No product tests or builds were run for this preservation change.

The active source remains in the ordinary repository directories. Existing
branches and pull requests are unchanged. This collection contains product
source and test definitions only; private operational records, credentials,
account state and historical private requirement documents are excluded.
