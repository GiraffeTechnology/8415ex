# Complete business-terms sections

The NFT detail view accepts an optional fixed `section` on a clause supplied by the existing original detail reader. The existing source verifier, coverage verification and identity-excluding declaration remain required. A category is display metadata; it does not establish completeness, a signature, registration or execution eligibility.

The eight supported values are `commodity`, `quantity`, `storage-delivery`, `currencies`, `deadlines`, `additional`, `signed-business-terms` and `revision-history`. Unknown, null and identity-bearing category values are refused through the existing unavailable projection. The original label and text remain unchanged. Legacy label/text-only clauses retain their existing schema and flat rendering.

When at least one original clause carries a category, the page displays fixed headings and keyboard-operable fragment links in all six existing locales. Each consecutive run gets its own local numeric anchor. Clauses remain in the original sequence and appear exactly once; repeated categories are not regrouped or deduplicated. Unclassified clauses remain visible under “Other supplied clauses”. The UI does not infer classifications from text, invent missing sections or insert default obligations.

Headings are informational translations. Signed-business text is escaped for HTML without translation, truncation or rewriting. Unchanged private originals remain private for original hash/signature verification; section metadata adds no identity field, raw document export or new authority path. The complete signed-business-terms section is an identity-excluding view, not a download of the private signed original. Revision history is displayed only when supplied, never fabricated from a current timestamp.

This stage builds on the per-record signature observation branch. It preserves that stage's separate signature records and conservative legacy summaries. Its parent must be accepted and any review fixes reconciled before this branch is retargeted to main and validated as an exact combined source.

Eight regression definitions cover legacy compatibility, all headings/locales, mixed and repeated category ordering, invalid categories, source/coverage refusal, long escaped obligations, unchanged original records and missing terms. Author execution is **NOT_RUN**. Browser keyboard, mobile layout, original document coverage, signatures and native business acceptance remain **NOT_RUN** or **OPEN** pending their actual evidence. No deployment is claimed.
