# Same-block remint history workbench

`RemintHistoryWorkbenchServer` extends the original remint-review workbench with `GET /remint-history`. The original gas, registration, review and workbench routes remain mounted. The host explicitly supplies a `RemintChainHistoryBinding` for the same receipt, original Sepolia contract, stable bill key, initial token and trusted original snapshot reader; there is no default reader, contract, endpoint or fixture.

The reader receives only the installed chain/contract/bill scope plus the selected positive uint256 token ID. It must authenticate the original provider and execute declarationOf, predecessorOf, successorOf, activeTokenForBill and the applicable reciprocal-link reads at one exact observed block. Its returned scope and block must bind those responses. These local shape and semantic checks do not authenticate an arbitrary source, and the binding must never be assembled from request-body callbacks.

The page decodes the retained declaration and requires its original bill key, checks reciprocal immediate links and the active mapping, then displays links in both directions and to the current active NFT. A predecessor may have an immediate successor distinct from the final active NFT after several replacements. Missing links retain zero at read; malformed, conflicting, unavailable or wrong-scope responses produce a localized unavailable page rather than no history. Retained declarations do not prove that a token remains active. No ownership, burn, transaction-finality or complete-business-history conclusion is inferred from these getters alone.

All six supported locales retain the selected token across language navigation. Chain, contract, bill and reader selection are unavailable to the route. The public page contains protocol token/block identifiers, with no wallet/contract address or raw source errors. Original private declarations, registration, trade and funds evidence remain with their existing readers. Existing complete terms remain on the separate original review path; this page neither rewrites nor substitutes for them. POST returns405 without reading or dispatching a remint.

This stage depends on the ABI decoder in PR212 and implements a navigable read portion of EX-REMINT-04/T-67. Eight approved-Linux synthetic test definitions cover six locales, selection, original scope, same-block response shape, reciprocal links, failures, POST and existing routes. Author execution is NOT_RUN. No live contract binding has been installed or queried by this source change. Actual browser, original reader authentication and native/chain acceptance remain outstanding.
