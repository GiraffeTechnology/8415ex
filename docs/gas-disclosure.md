# Pre-trade gas disclosure

This new initial module supplies exact ETH and USD amounts for confirmation content. It uses only caller-supplied gas estimates, ETH/USD rate, source references, observation times and explicit validity intervals. It selects no RPC, price feed, wallet, production timeout or fee policy.

`require_disclosure(actions, quote, now)` refuses missing estimates, missing rates, future or expired observations, duplicate actions, mixed networks and values that would require floating-point coercion. Each action lists its estimated ETH and USD amount and whether it is conditional. Unlisted actions are explicitly not estimated rather than silently priced at zero. No total combines unconditional and conditional actions. Input validity boundaries are supplied explicitly; this module does not invent a freshness SLA.

Gas units multiplied by wei per gas gives estimated wei. ETH uses 18 decimal places. A quote is integer micro-USD per ETH; USD is represented exactly with up to 24 decimal places. There is no float conversion or rounding to a display cent. Both estimate and quote timestamps are retained. The HTML renderer escapes values and displays the numbers, timing and coverage rather than a disclaimer alone.

These are calculations and presentation, not source authentication or permission. The integrating caller must obtain estimates and the rate from the original approved provider, bind the action to the correct asset and current wallet context, call this refusal boundary before confirmation, and preserve the wallet's existing authorization checks. A valid disclosure is not permission to submit. No extra Agent approval workflow is introduced. Principal conversion, fee apportionment, automatic over-estimate limits and unlimited authority are not implemented.

Six focused test methods are authored in integration/test_gas_disclosure.py. Suggested Linux command for the independent test owner: python3 -B -m unittest integration.test_gas_disclosure. They are NOT_RUN at initial handoff. No RPC, quote-provider, browser, signing, transaction, deployment or production result is claimed. Existing UI and domain files are unchanged; live UI submission gating and authoritative source integration remain separate work. This initial source supports the new pre-trade disclosure requirement but does not establish complete application acceptance.
