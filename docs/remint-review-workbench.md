# Read-only replacement terms on the integrated workbench

The new server subclass retains the original integrated gas, registration and
workbench routes and adds GET /remint-review with the same six supported locales.
An installed RemintReviewBinding identifies the original current and proposed
receipt versions. Its trusted reader supplies two existing identity-excluding
public-detail projections from one original document context. HTTP accepts only
one optional locale; no receipt, terms, holder result, signature or outcome is
accepted from query/body data.

The two versions may retain the same stable receipt ID. The original reader must
bind their actual document versions; this view introduces no distinct-receipt-ID
eligibility rule. The existing remint path owns the distinct new NFT identity.

The page preserves every projected clause in order on each side, escapes text
and indicates whether the complete projected clause lists differ. It refuses
missing or unverified projections, mismatched receipt versions, address-bearing
clauses and unknown clause fields, rather than exposing a partial or rewritten
document. All terms come from the original reader; missing terms are not filled
with examples. The unchanged full signed original remains private upstream.

Status fields alone do not authenticate arbitrary input. The host must bind the
original resolver/verifier and its identity exclusion/coverage checks before
supplying these read models. This module does not manufacture a verifier or claim
a proposed NFT has already been minted. It invokes no remint execution, journal,
wallet, holder/owner eligibility, fee or signature callback. The existing native
execution path retains Holder possession and Holder = Owner checks, with no new
clearance, liability-migration or approval step introduced by this view.

POST to this entry is refused and its unread body connection is closed. Source
failure produces a localized unavailable page without resolver diagnostics or
partial terms; other integrated routes remain usable. Existing host checks and
response security/cache headers remain inherited. No deployment address, new
server resource, production reader or live mount is selected by source creation.
This read-only composition is not a completed remint transaction UI or full PRD
acceptance, and it does not install or replace the running workbench.

Nine loopback regression definitions cover six locales, original version binding,
escaped text, privacy refusal, unavailable sources, POST rejection and retained
gas routing. They are NOT_RUN. No local product tests, imports, syntax/type checks,
builds or packaging were performed.
