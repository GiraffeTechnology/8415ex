# Current PRD narratives in presentation and film preparation

The material exporters share the six scenario titles, required main source and
required outcome from `materials/demo-narrative.mjs`. Its public PRD identity
pins the current section 15 text. This removes retired physical-collection
headings and distinguishes intermediate ordinary-wallet ETH shortage from an
exhausted rollback gas budget.

The narrative is an explanation of current requirements. It is not an
assertion that existing captures implement them. Both exporters retain original
runtime commit/tree, screenshots, video bytes, run IDs, recorded routes, counts,
errors and timing. They add the required main source alongside the recorded
route and explicitly mark scenario semantics unverified. A source-name match
is only a string identity comparison; it does not verify that source, its
registration path or the scenario outcome.

Film captions and the HTML player identify requirement labels separately from
recorded footage. PPT scenario captions say that the heading is a requirement
label; speaker notes retain the required behavior and PRD identity alongside
original capture references. The source manifests keep `finalAcceptance=NOT_RUN`
and a `requirementsNarrative` marker with `requirementLabelsOnly=true` and
`scenarioSemanticsVerified=false`. No capture is rewritten, upgraded or
silently rejected because its route differs from the required main fixture.

Current scope is:

- DEMO-01: Single bill-of-lading transfer, REG_DIRECT.
- DEMO-02: Continuous trading and prefix release, REG_ELECTRONIC.
- DEMO-03: Registration of B is refused, REG_INTERMEDIARY.
- DEMO-04: Refused registration of C preserves AB, REG_DIRECT.
- DEMO-05: Intermediate ordinary-wallet ETH shortage, REG_ELECTRONIC.
- DEMO-06: Cutoff failure and recovery boundary, REG_INTERMEDIARY.

Required return is one direct asset-control return to effective holder; original
buyer refunds and ETH gas evidence stay separate. Bill inspection and retained
history do not create physical collection, collection-driven burn or expired
reopening. These labels do not certify actual fund freezes, Oracle writes,
wallet authority, direct return, atomic remint or successful recovery.

No presentation or movie was generated by this source change. Existing
`materials/test_native-presentation.mjs` and `materials/test_native-film.mjs`
remain the independent Linux CI checks for retained capture/video identity and
export contracts. Author execution is NOT_RUN. Actual source-bound media,
rendering, captions/playback, visual/content review and all current demonstration
acceptance remain separate required evidence.
