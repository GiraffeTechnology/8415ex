# Deferred module runtime contract

This source increment implements the deferred accounting engine and its existing-aggregate checkpoint boundary. It does not deploy a vault, select an RPC, configure a signer, create bridge liquidity or certify a real cross-chain trade.

`DeferredSettlement` consumes canonical `Fact` records exclusively through a caller-supplied trusted `EvidenceVerifier`. No HTTP payload may instantiate facts as verified observations. The original application must supply verification of finalized lock evidence, exact seller consent, wallet admission including the unchanged gas/authority gates, ordered registration cut, unencumbered principal allocation, bounded liquidation quote and destination effect receipts. The profile must bind the verified NFT0-permitted stablecoin and original vault/escrow identities; display symbols are not an admission mechanism.

`DeferredCheckpoint` uses the original `AggregateCheckpointStore` and its explicit file-backed synchronous journal. Its component is `deferred-settlement`; it preserves every supplied original component byte-for-byte. No database path or schema migration is selected. `apply` validates a complete state and saves it with the caller's exact generation. `dispatch_once` saves UNKNOWN before calling an original execution port. A stale writer or a failed/uncertain save cannot dispatch. A returned executor success is still UNKNOWN until separately verified destination evidence is committed. Do not call model mutation methods outside this durable service in a live runtime.

The original execution port receives a committed operation with exact identity, obligation, destination asset/chain/recipient, amount, quote commitment and collateral spending cap. It must preserve wallet authorization and perform original native reconciliation; it must not infer a bridge or liquidity route from the presence of this module. Cancellation and definitive non-execution proof recovery are not yet provided by this source increment. No blind retry is allowed.

Implemented state distinctions include registration-first debt without NFT rollback, deadline-first rollback, same-currency top-up, early registered payment, debt liquidation versus rollback-gas liquidation, source versus destination effect evidence, partial liquidation proceeds, excess refund, verified collateral remainder and final unlock. The initial engine permits one active obligation per distinct lock; multi-obligation allocation within one lock remains a development item, not a product requirement or an implemented guarantee.

The existing UI is unchanged. Its later wiring must use private state projections without publishing wallet identifiers or diagnostics. Original receipt transfer/rollback authority, actual trusted proof implementations, original vault/native operation composition, UI wiring, real Hoodi lock and Sepolia receipts remain separate integration work. The tests use explicitly synthetic facts and file-backed local fixtures in CI. They do not constitute a production verifier or live financial execution.

## Recovery refinements

Deadline processing requires an authenticated original Oracle cut as of the settlement deadline before classifying an unobserved registration as absent. Missing evidence returns REGISTRATION_RECONCILIATION_REQUIRED and does not open a rollback dispatch. A timely cut received late cancels only unsent recovery preparations; conflicting already-dispatched recovery stays a reconciliation error rather than silently rewriting effects.

An unlock preparation reserves its entire lock before dispatch. Lock-level pending operations prevent new borrowing, and dispatch revalidates the reservation. Each liquidation reserves its maximum source collateral across partial destination receipts. A separate finalized liquidation-source fact reduces collateral units by actual consumption and releases only the unused part of that source cap. Destination funds alone never release source collateral reservations. Identical preparation retries return the original committed operation; changed amount, quote, purpose or obligation is refused.
