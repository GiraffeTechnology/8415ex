# Read-only market browser collection

The deployed empty catalogue can serve the commodity market, collateral selector
and scenario selector without a native receipt or simulation console. Use
`capture_market(page, original_loopback_origin, source)` in the existing browser
material collector to observe those three fixed routes in each of the original
six supported locales. The caller supplies its already permitted async Page and
exact commit/tree; the function starts no browser or context and selects no host,
credential, provider or wallet.

The collector reads the existing /healthz before and after the journey, keeps the
raw bytes and compares the declared commit/tree to the requested source. It
requires HTTP 200, the exact selected same-origin path/query and a visible page
before retaining each PNG. It rechecks navigation after the screenshot. Missing
selectors, source changes, unexpected navigation or size failures raise; the
function returns no complete capture on a partial journey. The host preserves
any partial original logs through its existing evidence handling.

Each image is at most 8 MiB and all retained bytes are at most 64 MiB. Health
observations are individually bounded to 256 KiB. The output stays in memory;
the existing pack_capture can package its whitelisted screen/evidence paths.
Browser/transport timeout policy and Page lifecycle remain the original host's.

This is a distinct 8415ex-market-browser-materials/1 manifest with
ACTUAL_BROWSER_SCREENSHOTS_OF_READ_ONLY_MARKET content. Declared source is not
independent installed-code identity. HTTP 200 and PNG bytes do not prove correct
translations or independent visual acceptance. The manifest keeps those checks,
native receipt/six-scenario execution, provider/signing/chain and full delivery
unverified or NOT_RUN. It is not the native 12-scene capture input for final
presentation or film exporters; it cannot substitute for their evidence.

No simulation forms, command requests, forced reference refresh, receipt lookup
or financial effects are performed. Ordinary browser/native acceptance remains
with the original QA owner. Six authored regression methods cover route/locale
coverage, evidence limits, changed source, missing selector, navigation and
image limits. Author tests, syntax checks, browser capture and export are NOT_RUN.
