# Original Oracle as-of HTTP composition

The complete candidate retains the original read-only Oracle as-of route and
canonical projection join. The installed host supplies the actual original
source identity, transport origin and canonical EX segment/registry mapping
verifier. This composition chooses no origin, registry, credential or provider.

Selection first reads the entry covering the requested instant, then preserves
the existing bounded head/version/holder/finality/head join. The selected entry
must remain the same complete record; a missing or refused selection does not
fall back to the latest entry or a guessed version. Holder, effective-time
coverage, cutoff and finality remain independent observations.

All calls are original GET routes. A successful joined read creates no holder
writer, finality writer, atomic settlement authority or financial dispatch.
It does not turn Holder equality or current finality into an ordinary trading
prerequisite. Real canonical mapping and original execution-time checks remain
the original application's responsibility.

Four synthetic definitions join the actual bounded HTTP transport with the
original projection consumer, checking exact six-read correlation, independent
cutoff/finality, refusal without fallback and inconsistent-holder/instant
isolation. Author product execution is NOT_RUN; simulated source identities and
mapping callbacks do not establish current Oracle or native financial evidence.

The current-main direct-return session-authentication test change is retained
as its exact original blob and ancestry alongside prior recovered-draft fixes.
Other candidate features and translation-table classifications are preserved.
This source composition does not modify a live service or its configuration.
