# Recovered unsigned remint editor and read-view composition

The recovered workbench now mounts the unsigned editor on the actual handler
selected by the existing serialized/checkpoint factories. When original history
or receipt readers are present, their GET routes and read-only POST refusals
remain reachable beside review, gas, registration, market and optional selectors.
Navigation keeps each original link once in each of the six supported locales.

The editor retains its original typed currency, business-field, attribute and
template/voucher choices. The composition forwards optional original choice
callbacks without invoking them during construction. Without a declaration
reader it leaves the editor absent; unavailable editor data does not disable
other routes. All bindings use the same loaded serialized access and receipt.

Draft POST requests retain the editor's original Origin, CSRF, bounded form and
typed-input checks. A preview has no save, signature, native submission, burn or
mint effect. Original read-view bindings remain independent; rendering a draft
does not perform a history, receipt, eligibility or journal preflight.

The new integration definitions exercise HTTP route coexistence, six-language
navigation, lazy reader forwarding, unsigned preview isolation, unavailable and
missing readers, CSRF refusal and same-access mounting. They use synthetic
original fixtures. Author execution is NOT_RUN; current-source CI, browser,
deployment and live native/chain acceptance require their own actual evidence.
