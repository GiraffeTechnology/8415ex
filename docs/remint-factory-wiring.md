# Remint read views through the original host factories

The serialized and checkpoint workbench factories now accept optional `remint_history` and `remint_receipt` bindings. They mount the existing unified remint server when either binding is supplied. The same serialized access, primary gateway, original gas and registration controllers, complete terms review, directory bindings and source stamps remain in use. The checkpoint factory loads once and passes the original read bindings to that loaded instance. Recovered UI and checkpointed-command composition already forward their original keyword options through this factory.

Both bindings are application-supplied objects from the existing remint view modules. This factory does not choose a contract, bill, transaction, reader, endpoint or port. It does not call either reader while constructing the server. The original constructor validates supplied binding identity; this is display wiring consistency and never a new command preflight. Each route still invokes only its own reader. An absent optional reader or failed read affects that view, without disabling the original gas, review or command path. Supplying neither optional binding retains the original review server and behavior.

The host continues to own authenticated same-block history ports and the exact receipt observer/context. One read binding is not proof of the other view, transaction finality, UNKNOWN reconciliation, financial release or remint acceptance. No journal or checkpoint is created, saved, replaced or migrated by this change. Missing saved state retains the original unavailable result.

This stage depends on the unified remint workbench source. It adds eight synthetic supported-Linux integration definitions for same-access/source propagation, optional absence/failure, actual original receipt rendering, POST refusal, unchanged gateway behavior, one checkpoint load and absent-checkpoint isolation. Author execution is NOT_RUN. Current-source CI, runtime configuration, browser, native financial and chain evidence remain separate outstanding work.
